# Hang Creator — «Тихий ритм»

Редактор табулатур для ханга. Откройте **index.html** в браузере — устанавливать Python или другие программы не нужно. Интернет, npm и внешние библиотеки для работы не нужны.


## Онлайн-версия

[Открыть десктопный редактор](https://khlebnikovhub.github.io/hang-creator/)

[Открыть мобильную версию](https://khlebnikovhub.github.io/quiet-rhythm-mobile/)

Для загрузки онлайн-версии нужен интернет. «Сохранить изменения» записывает табулатуру в выбранную локальную папку либо скачивает JSON; файлы репозитория на GitHub эта кнопка не изменяет. На компьютере можно выбрать существующую папку со своими табулатурами или создать новую.

Для работы без интернета [скачайте ZIP приложения](https://github.com/KhlebnikovHub/hang-creator/archive/refs/heads/main.zip), распакуйте его и откройте `index.html`. В папке `tabs` находятся три исходных примера.

## Запуск

1. Откройте **index.html** из этой папки.
2. Нажмите слева **«Выбрать папку tabs»** и выберите папку **tabs рядом с index.html**. Приложение прочитает из неё табулатуры и будет сохранять их туда. Обычно достаточно выбрать папку один раз.
3. Выберите табулатуру в библиотеке или создайте новую. Другие файлы можно импортировать кнопкой **«Открыть JSON / TXT»**.
4. После редактирования нажмите **«Сохранить изменения»** или **Ctrl+S** / **Cmd+S**. Если папка ещё не выбрана, первое сохранение предложит выбрать её.

Если кнопки выбора папки нет, браузер использует сохранение отдельного JSON или скачивание; подробности ниже.

## Сохранение и перенос

- **«Сохранить изменения»** сохраняет текущую табулатуру в JSON со всеми её настройками: размером, делениями тактов, режимом счёта, слогами, ударами, аккордами, партиями R/L, темпом и заметками.
- В выбранной папке файл сохраняется под постоянным ID табулатуры: `id.json`. Переименование произведения обновляет этот же файл, повторно выбирать имя и место не нужно.
- Папка запоминается для следующих запусков. Если разрешение осталось действующим, приложение автоматически прочитает её при открытии страницы. Если доступ нужно подтвердить, нажмите слева **«Разрешить доступ»** — выбирать папку заново не требуется. **«Изменить»** позволяет назначить другую папку.
- При чтении папки загружаются корректные JSON-табулатуры; повреждённые файлы пропускаются. Несохранённые правки из рабочей автокопии сохраняются при повторном чтении папки.
- Импортированный извне JSON или TXT сохраняется как отдельная табулатура в выбранную папку. Исходный файл не перезаписывается; TXT преобразуется в JSON.
- **«↓ Копия JSON»** всегда скачивает отдельную копию текущей табулатуры. **«Экспорт PNG»** сохраняет изображение для печати и отправки.

Если браузер не поддерживает доступ к папке, остаётся сохранение отдельного файла: при первом сохранении выберите JSON, а следующие нажатия обновят его. Открытие JSON через поддерживаемый системный диалог также связывает табулатуру с этим файлом. Эта связь действует до обновления или закрытия страницы; после нового запуска откройте JSON заново. Если прямая запись недоступна, приложение скачивает JSON в загрузки браузера. Импорт через обычный выбор файла открывает копию без связи с исходным файлом.

Приложение также автоматически оставляет рабочую копию в хранилище браузера. Это отдельная автокопия: она не обновляет JSON на диске и не переносится вместе с папкой. **Перед закрытием вкладки нажмите «Сохранить изменения»**, чтобы сохранить работу в файл.

Для переноса приложения скопируйте всю папку **hang-creator** и сохранённые JSON, если они лежат в другом месте. Для переноса одной табулатуры достаточно её JSON: откройте его в приложении на другом устройстве. Сохранение и экспорт относятся к текущей табулатуре, а не ко всей библиотеке.

Доступ к папке и его сохранение между запусками зависят от браузера, разрешений и доступности хранилища браузера, в том числе при открытии через `file://`. Первоначальный явный выбор папки обязателен: открытие index.html само по себе не разрешает читать или изменять соседнюю tabs. Если браузер не предоставляет файловый доступ, сохраняйте JSON скачиванием; одинаковая прямая запись в папку на всех платформах для обычной HTML-страницы недоступна. Подробнее: [MDN: выбор папки и поддержка браузерами](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker).

## Работа с табулатурами

- **R/L в любой отдельной ячейке:** выберите позицию и нажмите «Добавить R/L». Прежний удар станет R; выберите L и добавьте второй. Соседние ячейки и общий режим остаются прежними. «Без рук здесь» объединяет только выбранную позицию в обычный аккорд. Дробление наследует локальный режим; JSON, PNG, прослушивание и отмена поддерживают смешанную запись.
- **Дробите прямо в сетке:** выберите ячейку → ÷ 2 или ÷ 3. Можно делить повторно, например только «и» на две шестнадцатые. Точная длительность показана рядом; размер такта и время остальных ударов сохраняются. «Собрать» соединяет части, предупреждая о заполненных позициях, которые исчезнут.
- **Пишите маркером:** «Маркер» → удар на панели → нажатия или движение по ячейкам. «Ластик» убирает удар выбранной руки; один жест отменяется одним Ctrl+Z. «Курсор» возвращает обычный ввод.
- **Меняйте слоги:** «Слог…» меняет только выбранную позицию; пустое поле возвращает автоматический вариант. «Настроить слоги…» задаёт восемь слогов для всей табулатуры с предпросмотром. Исходный шаблон — `Ta Ka Di Mi · Ta Ka Jo Nu`. Для `PaKaDiMi` замените первое `Ta` на `Pa`. Явно заданные слоги ячеек, долей и фраз сохраняются.
- **Обе руки в одной ячейке:** «R + L в одной ячейке» показывает R синим, L красным, без двух отдельных рядов сетки. Выбор руки находится на панели ввода; «Цвет рук» включает бесцветный вид с сохранением R/L. JSON, PNG и прослушивание учитывают обе партии.
- Выберите табулатуру в библиотеке или создайте новую.
- Задайте размер и режим записи: «Счёт», «Коннакол» или «Гибрид». В гибриде номер доли сохраняется над группой слогов.
- В блоке «Внутри ритма» выберите «Этот такт» или «Все такты» и настройте деление каждой доли независимо.
- Кликните по ячейке и введите удар с клавиатуры или панели D/S/K, 1–12. «Автопереход» можно отключить.
- Двойной клик, Enter или «Аккорд» открывают точный ввод, например `D/4` или `2/4/8`. Delete очищает ячейку.
- Меню **⋯** у такта позволяет вставить пустой такт с тем же ритмом, переставить такт и очистить удары. Рядом находятся дублирование и удаление.
- Панель прослушивания играет всё произведение или выбранный такт. Доступны повтор и метроном. **Пробел** запускает и останавливает, **Escape** останавливает. Звуки условные, для проверки ритма.
- **Ctrl+Z** отменяет изменение; **Ctrl+Shift+Z** или **Ctrl+Y** возвращают его. D/S/K и эти сочетания работают также при русской раскладке.
- **«Создать копию»** внизу редактора добавляет отдельную копию произведения в библиотеку.

Подробная справка доступна по кнопке **?** рядом с настройками деления.

## Дополнительный запуск через локальный сервер

Этот режим позволяет автоматически читать и сохранять табулатуры в папке **tabs** рядом с приложением без выбора папки в браузере.

1. Установите Python 3.10 или новее с добавлением в PATH.
2. На Windows дважды нажмите **run.bat**. Редактор откроется по адресу **http://127.0.0.1:8765/**. На других платформах выполните `python3 server.py` из этой папки.
3. Оставьте окно сервера открытым во время работы. Для остановки нажмите **Ctrl+C** в этом окне.

В этом режиме изменения автоматически записываются в **tabs**; **«Сохранить изменения»** выполняет запись сразу. После внешнего изменения JSON в этой папке обновите страницу. Если порт занят, закройте другой сервер либо запустите `python server.py --port 8766` (или `python3` вместо `python`). Для обычного открытия **index.html** этот режим и Python не нужны.

## Состав папки

- **index.html**, **styles.css** — интерфейс.
- **app.js** — редактор и библиотека.
- **file-storage.js** — открытие и сохранение JSON в браузере, скачивание копий.
- **directory-storage.js** — выбор и запоминание папки табулатур, чтение и запись JSON в неё.
- **core.js** — музыкальная модель, проверка данных и импорт TXT.
- **playback.js** — прослушивание и метроном.
- **export.js** — экспорт PNG.
- **sample-tabs.js** — встроенные примеры для работы без сервера.
- **server.py**, **run.bat** — дополнительный локальный сервер и его запуск.
- **tabs/** — редактируемые табулатуры в JSON, включая три исходных примера.
